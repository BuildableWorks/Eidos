# Roles

The response contracts for this definition — who is in the seat, and how the agent should respond to them. Reshaped from the book seed: the Editor and Reader roles were dropped (this film has neither yet), and the two that remain were kept as they shipped.

- [Framework Owner](framework-owner.md) — holds intent, scope, and decisions.
- [Collaborator](collaborator.md) — drafts alongside the owner.

Each person picks one in their personal, gitignored `_eidos/me.md` and calibrates it with `whoami`. A role is a baseline, not a cage.
