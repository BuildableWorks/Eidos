# The Salt Road

> **Start here.** This is the Eidos definition for **The Salt Road** — a short film about a
> cartographer who can no longer read her own maps, and the last commission she takes anyway.

Not a screenplay. The definition of one: what each scene is for, what it promises, and what it
deliberately leaves out — true before a page is written and still true after.

## Where things are

- **[Frames](Frames/index.md)** — the premise, the audience, the voice, the market.
- **[Scenes](Scenes/index.md)** — one file per scene, grouped by act.
- **[Framework Map](Framework%20Map.canvas)** — the generated canvas, openable in Obsidian.

The full index — collections, flavors, canvas styles, and the property Schema — is in
[`_eidos/Framework.md`](_eidos/Framework.md).

## Why this example exists

The software example next door shows Eidos where it started. This one shows the claim the standard
actually makes: that `Specs` and `domains` are the default seed, not the essence. Nothing here is
called a spec. Scenes group by `act`. The canvas draws cards from `## Logline` because this framework
says so. Every skill works identically across both.

It began as the **book** seed and was reshaped from there — `Chapters` → `Scenes`, `part` → `act`, a
new `pov` property, and scene shapes in place of chapter shapes. That reshaping is the normal case,
not a special one.
