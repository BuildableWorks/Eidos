## How it is organized

- **[Frames](frames/)**: four pages everything else is checked against: the question, what is already known, how you will know, and who could be affected. Write these first, and come back when the question shifts.
- **[Investigations](investigations/)**: one page per line of inquiry. Group them in folders as the work grows: a strand of the research, the studies in it, and the experiments in each study. Add one when you start asking something new.
- **[Decisions](decisions/)**: one note per call that changes what the results can show, such as a change of method, an analysis choice, or a step away from the plan. Add one when you make the call, so someone can sign it off.
- **[Backlog](backlog/)**: the to-do list: runs, analyses, reading, writing, and reviews. Add a task for any piece of work, and link it to the page it serves.
- **[Data](data/)**: small datasets, codebooks, and data dictionaries. Large or sensitive raw data stays where it is kept safe, with a link here.
- **[Figures](figures/)**: charts, diagrams, and slides. Keep a figure together with the data and script that made it.
- **[Literature](literature/)**: the papers and reports you cite, one file each.

## Where to start

1. Fill in the question page in [Frames](frames/): one sentence, ending in a question mark.
2. Add your first page in [Investigations](investigations/), and write down what result would change your mind before you look at any data.
